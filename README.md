College Fee Management System

A desktop-based College Fee Management System developed using Python, Tkinter, and SQLite.

Features

* Student registration and management
* Student fee details management
* Fee collection
* Automatic balance calculation
* Fee receipt generation
* Student search
* Fee reports
* SQLite database storage
* Simple and user-friendly Tkinter interface

Technologies Used

* Python
* Tkinter
* SQLite3
* HTML
* Python Standard Library

How to Run

1. Install Python 3.x.
2. Clone or download this repository.
3. Open the project folder in VS Code or IDLE.
4. Run:

python main.py

Database

The application uses SQLite for storing student and fee-related records.

The local database file is not included in this repository to protect student data.

Purpose

This project was developed to simplify college student fee management and reduce manual record-keeping.
